# Medium:-

## Test() :-

### test() :- 
- Create test

### test.only()	:- 
- Run only one test
```
test.only('Login Test', async ({ page }) => {
    // Only Run this 
});

test('Login Test 1', async ({ page }) => { 
    // avoid this
});

test('Login Test 2', async ({ page }) => { 
    // avoid this
});
```

### test.skip() :- 
- Intentionally doesn't run the test.
```
test.skip('Safari Test', async ({ page }) => {
    // Not executed
});

Especially useful for conditions:

test('Browser Test', async ({ page, browserName }) => {

    test.skip(
        browserName === 'webkit',
        'Feature not supported on WebKit'
    );

    // Test
});
```
- Think: skip() = This test is valid, but I intentionally don't want it executed under this condition.

### test.fixme() :- 
- Marks a test as needing repair and doesn't run the test.
```
test.fixme('Payment Test', async ({ page }) => {
    // Not executed
});
```
Use when:
- Test itself is broken
- Feature is badly broken
- Running the test is pointless/expensive
- Test needs future investigation
Think: fixme() = Known problem; don't execute it for now.

### test.fail() :-
- The test still executes, but you tell Playwright that failure is expected.
```
test('Payment Test', async ({ page }) => {
    test.fail();

    await expect(page.getByText('Payment Successful'))
        .toBeVisible();
});
```
Important behavior:
- Test fails  → Expected behavior
- Test passes → Unexpected pass → Playwright reports failure
- Use it when there is a known application bug, but you still want the test executed.

### test.describe()	:-
- Group tests
```
test.describe('Login Tests', () => { 
    test('Valid Login', async ({ page }) => { }); 
    test('Invalid Login', async ({ page }) => { }); 
});
```

### test.describe.only() :-
- Run only group
### test.describe.skip() :-
- Skip group
### test.describe.configure() :- 
- Configure group execution
### test.beforeEach() :- 
- Before every test
### test.afterEach() :-
- After every test
### test.beforeAll() :-
- Once before tests
### test.afterAll() :- 
- Once after tests
### test.use() :- 
- Override test configuration
### test.setTimeout() :- 
- Set timeout
### test.slow() :- 
- Mark test slow
### test.info() :- 
- Current test information
### test.step() :- 
- Create reportable test steps
