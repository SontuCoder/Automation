# Frames and Windows in Playwright

## 1. Frames / iFrames
A **frame** is a webpage embedded inside another webpage.
HTML example:
```html
<iframe src="payment.html"></iframe>
```
Structure:
```text
Page
│
├── Main Frame
│
└── iframe
    └── Elements inside iframe
```
You cannot always access an iframe element directly from the main page. You must first target the frame.
---
# `frameLocator()`
Recommended way to work with an iframe.
```typescript
const frame = page.frameLocator('#payment-frame');

await frame.getByLabel('Card Number').fill('123456');
await frame.getByRole('button', { name: 'Pay' }).click();
```
Example:
```html
<iframe id="login-frame"></iframe>
```
```typescript
const frame = page.frameLocator('#login-frame');

await frame.getByLabel('Username').fill('admin');
await frame.getByLabel('Password').fill('1234');
await frame.getByRole('button', { name: 'Login' }).click();
```

### Direct usage
```typescript
await page
    .frameLocator('#login-frame')
    .getByLabel('Username')
    .fill('admin');
```
---

# `page.frame()`
You can also get a `Frame` object.
By frame name:
```typescript
const frame = page.frame({ name: 'paymentFrame' });
```
By URL:
```typescript
const frame = page.frame({
    url: /payment/
});
```
Then:
```typescript
await frame?.getByLabel('Card Number').fill('123456');
```
---

# Get All Frames

```typescript
const frames = page.frames();
console.log(frames.length);
```
Loop:
```typescript
for (const frame of page.frames()) {
    console.log(frame.url());
}
```
---

# Main Frame
```typescript
const mainFrame = page.mainFrame();
```
---

# Nested Frames
If an iframe exists inside another iframe:
```typescript
const outerFrame = page.frameLocator('#outer-frame');
const innerFrame = outerFrame.frameLocator('#inner-frame');
await innerFrame.getByRole('button', {
    name: 'Submit'
}).click();
```
Structure:
```text
Page
└── Outer iframe
      └── Inner iframe
            └── Submit Button
```
---

# Important Frame Methods

| Method                | Purpose                       |
| --------------------- | ----------------------------- |
| `page.frameLocator()` | Locate iframe                 |
| `page.frame()`        | Get a Frame object            |
| `page.frames()`       | Get all frames                |
| `page.mainFrame()`    | Get main frame                |
| `frame.url()`         | Get frame URL                 |
| `frame.name()`        | Get frame name                |
| `frame.locator()`     | Locate element inside frame   |
| `frame.getByRole()`   | Semantic locator inside frame |

### Best Practice
Prefer:
```typescript
page.frameLocator(...)
```
because it works naturally with Playwright locators and auto-waiting.

# 2. Windows / Tabs
In Playwright:
> **Each browser window or tab is represented by a `Page`.**
Example:
```text
Browser
│
└── BrowserContext
      │
      ├── Page 1 → Main Tab
      ├── Page 2 → New Tab
      └── Page 3 → Popup Window
```
---

# New Tab / Popup
Suppose clicking a button opens a new tab:
```typescript
const newPagePromise = page.waitForEvent('popup');
await page.getByText('Open New Window').click();
const newPage = await newPagePromise;
```
Now:
```typescript
await newPage.waitForLoadState();
console.log(await newPage.title());
```
---

# Complete Example
```typescript
test('Handle new tab', async ({ page }) => {
    await page.goto('https://example.com');
    const newPagePromise = page.waitForEvent('popup');
    await page.getByRole('link', {
        name: 'Open Details'
    }).click();
    const newPage = await newPagePromise;
    await newPage.waitForLoadState();
    console.log(await newPage.title());
});
```
Important:
```typescript
const newPagePromise = page.waitForEvent('popup');
```
must normally be created **before** clicking.
Correct:
```typescript
const popupPromise = page.waitForEvent('popup');
await button.click();
const popup = await popupPromise;
```
Avoid:
```typescript
await button.click();
const popup = await page.waitForEvent('popup');
```
because the popup may already have opened.
---

# `context.waitForEvent('page')`
Another method:
```typescript
const pagePromise = context.waitForEvent('page');
await page.getByText('Open Window').click();
const newPage = await pagePromise;
```
Difference:
```text
page.waitForEvent('popup')
        ↓
Popup opened from this specific page

context.waitForEvent('page')
        ↓
Any new page created inside the BrowserContext
```
---

# Get All Open Windows/Tabs
```typescript
const pages = context.pages();
```
Example:
```typescript
console.log(context.pages().length);
```
Access:
```typescript
const pages = context.pages();
const firstPage = pages[0];
const secondPage = pages[1];
```
---

# Switch Between Windows
There is no Selenium-style:
```text
switchTo().window()
```
In Playwright, simply use the required `Page` object.
Example:
```typescript
await page.getByText('Home').click();
await newPage.getByText('Profile').click();
```
Think:
```text
page     → Original window
newPage  → New window/tab
```
---

# Close New Window
```typescript
await newPage.close();
```
Return to original page:
```typescript
await page.bringToFront();
```
Usually you can simply continue using:
```typescript
await page.getByText('Home').click();
```
---

# Wait for New Window + Action
A clean pattern:
```typescript
const [newPage] = await Promise.all([
    page.waitForEvent('popup'),
    page.getByText('Open Window').click()
]);
```
Then:
```typescript
await newPage.waitForLoadState();
console.log(await newPage.title());
```
---

# Frames vs Windows

| Frame                                | Window / Tab                           |
| ------------------------------------ | -------------------------------------- |
| Exists inside a page                 | Separate page/tab                      |
| Usually created using `<iframe>`     | Opens as new browser tab/window        |
| Use `frameLocator()`                 | Use `Page`                             |
| Same parent browser page             | Separate `Page` object                 |
| `page.frameLocator()`                | `page.waitForEvent('popup')`           |
| Cannot treat it as a normal new page | Can interact directly through new Page |

```text
iframe
   ↓
frameLocator()
   ↓
Element

New Tab / Window
   ↓
waitForEvent('popup')
   ↓
Page
   ↓
Element
```

## Interview Answer
**Frame:** An embedded webpage inside another page. In Playwright, use `frameLocator()` to interact with elements inside an iframe.
**Window/Tab:** Each browser tab or window is represented as a `Page`. When a click opens a new tab, use `page.waitForEvent('popup')` or `context.waitForEvent('page')` to capture the new `Page`.
