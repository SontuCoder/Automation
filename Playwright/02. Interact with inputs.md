# Basic 2:

## Input functions :- 

### .type() vs .fill()

- type() -> types characters one by one, similar to a user typing.
- if you have oldValue, then it type after that.
- fill() -> clears the existing value and enters the new value.
- if you have oldValue, then clear it and fill new value.
```
if input has old value:
input -> Hi

if using fill("Sontu") -> "Sontu"
if using type("Sontu") -> "HiSontu"
```
| `fill()` | `type()` |
|---|---|
| Clears existing text ✅ | Does not clear existing text ❌ |
| Does not type character-by-character ❌ | Types character-by-character ✅ |
| Cannot add typing delay ❌ | Can add typing delay ✅ |
| Faster ⭐ | Slower |
| Recommended for normal input ⭐⭐⭐ | Recommended when simulating typing ⭐⭐ |
| Partially simulates input | More closely simulates typing |

### Clear:
- use for clear input value.
```
await page.locator('#username').clear();
```

### Press:
- press() takes one key or key combination as a string. like "Send Hot key" in UiPath.
```
// ✅ Correct
await page.locator('#username').press('Enter');
await locator.press('Tab');
await locator.press('Escape');
await locator.press('Backspace');
await locator.press('Delete');
await locator.press('ArrowDown');
await locator.press('Control+A');
await locator.press('Control+V');

// ❌ Incorrect
await locator.press('Control', 'A');
```

### inputValue() :-
- Gets the current value of an input, textarea, or select element.
- inputValue() returns the value of the input, not its text content.
```
const value = await page.locator('#username').inputValue(); 
console.log(value);
```

### focus() :- 
- Moves the keyboard focus to an element.
```
await page.locator('#username').focus(); 
await page.keyboard.type('Subhadip');
```
- Useful when you need to perform keyboard actions on a specific input:
```
await page.locator('#username').focus();
await page.keyboard.press('Control+A');
```

### selectText() :-
- Selects all text inside an input or textarea.
```
await page.locator('#username').selectText();
```
