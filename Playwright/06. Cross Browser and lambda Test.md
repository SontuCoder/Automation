## LambdaTest with Playwright

### What is LambdaTest?

- LambdaTest is a **cloud-based testing platform**.
- It allows Playwright tests to run on remote browsers and operating systems.
- Playwright tests execute in the cloud instead of only on your local machine.

### Why use LambdaTest?

- Cross-browser testing
- Cross-OS testing
- Parallel execution
- Cloud-based execution
- Video recording
- Console logs
- Network logs
- Centralized test reports
- Useful for CI/CD pipelines

---

## Architecture

```text
Playwright Test
      ↓
WebSocket Connection
      ↓
LambdaTest Cloud
      ↓
Browser + OS
      ↓
Application
```

Example environments:

```text
Chrome + Windows
Edge + Windows
Firefox + Windows
Chrome + macOS
WebKit + macOS
```

---

## Local Playwright vs LambdaTest

| Local Playwright | LambdaTest |
|---|---|
| Runs on local PC | Runs in cloud |
| Uses local CPU/RAM | Uses cloud machines |
| Limited environments | Multiple Browser + OS combinations |
| Good for development | Good for regression/cross-browser |
| `browser.launch()` | `browser.connect()` |
| Local reports | Cloud reports/videos/logs |

## Credentials

LambdaTest provides:

```text
Username
Access Key
```

Set them as environment variables:

```powershell
$env:LT_USERNAME="username"
$env:LT_ACCESS_KEY="access_key"
```

Avoid storing credentials directly in source code.

```typescript
const browser = await chromium.connect({

```

```text
chromium.launch()
→ Starts browser locally

```

## Capabilities

Capabilities define which environment should be used.

```typescript
const capabilities = {
    browserName: 'Chrome',
    browserVersion: 'latest',

    'LT:Options': {
        platform: 'Windows 10',
        build: 'Regression Build',
        name: 'Login Test'
    }
};
```

Capabilities can define:

- Browser
- Browser version
- Operating system
- Test name
- Build name
- Video
- Console logs
- Network logs

# Cross-Browser Testing

Cross-browser testing means running the **same test on multiple browsers and operating systems**.

```text
Same Test
   ↓
├── Chrome + Windows
├── Edge + Windows
├── Firefox + Windows
└── Chrome + macOS
```

---

## Cross-Browser Test Example

```typescript
import { chromium } from 'playwright';

const environments = [

    {
        browserName: 'Chrome',
        browserVersion: 'latest',
        platform: 'Windows 10'
    },

    {
        browserName: 'MicrosoftEdge',
        browserVersion: 'latest',
        platform: 'Windows 11'
    },

    {
        browserName: 'Chrome',
        browserVersion: 'latest',
        platform: 'macOS Ventura'
    }

];

for (const environment of environments) {

    const capabilities = {

        browserName: environment.browserName,
        browserVersion: environment.browserVersion,

        'LT:Options': {

            platform: environment.platform,

            user: process.env.LT_USERNAME,
            accessKey: process.env.LT_ACCESS_KEY,

            build: 'Cross Browser Build',
            name: `Login Test - ${environment.browserName}`

        }

    };

    const browser = await chromium.connect({

        wsEndpoint:
            `wss://cdp.lambdatest.com/playwright?capabilities=${
                encodeURIComponent(
                    JSON.stringify(capabilities)
                )
            }`

    });

    const page = await browser.newPage();

    await page.goto('https://example.com');

    console.log(
        `${environment.browserName} : ${await page.title()}`
    );

    await browser.close();
}
```

## Normal Playwright Cross-Browser Testing

Without LambdaTest, Playwright uses `projects`:

```typescript
projects: [

    {
        name: 'chromium',
        use: {
            browserName: 'chromium'
        }
    },

    {
        name: 'firefox',
        use: {
            browserName: 'firefox'
        }
    },

    {
        name: 'webkit',
        use: {
            browserName: 'webkit'
        }
    }

]
```

Run:

```bash
npx playwright test
```

Flow:

```text
Same Test
   ↓
Playwright Projects
   ↓
├── Chromium
├── Firefox
└── WebKit
```

## Important

LambdaTest **does not replace Playwright**.

```text
Playwright
→ Automation framework

LambdaTest
→ Cloud infrastructure for running tests
```

### Easy Definition

> **LambdaTest allows Playwright tests to run remotely on multiple browser and operating-system combinations in the cloud.**

### Easy Memory

```text
Playwright = Write Automation

Cross Browser = Run Same Test on Different Browsers

LambdaTest = Run Automation on Cloud Browser + OS Combinations
```
